# FocusFlow+ – Student Productivity Dashboard

FocusFlow+ is a web-based productivity and study management application designed to help students organize their academic activities, build consistent habits, and improve time management. It provides an interactive dashboard with study tracking, a Pomodoro timer, subject management, habit tracking, and an XP-based progress system.

## 🚀 Features

- **Dashboard:** View study statistics, daily progress, and productivity.
- **Pomodoro Timer:** Manage focused study sessions and breaks.
- **Subject Management:** Add, organize, and track different subjects.
- **Habit Tracker:** Create and monitor daily habits.
- **Study Streaks:** Track consistency and daily achievements.
- **XP & Levels:** Earn experience points through productive activities.
- **Weekly Analytics:** Monitor study activity and progress.
- **Local Storage:** Save subjects, habits, study logs, and progress in the browser.

## ⚙️ How to Run

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Open the project folder.
3. Locate `wp.html`.
4. Open the file in any modern web browser.
5. Start managing your study sessions and habits!

No additional installation is required.

## 💾 Data Storage

The application uses browser Local Storage to retain user data, including subjects, habits, study sessions, and XP progress. Data remains available in the same browser unless its site data is cleared.

## 🎯 Project Objective

The objective of FocusFlow+ is to make student productivity more engaging by combining time management, habit building, study tracking, and gamification in one simple platform.
